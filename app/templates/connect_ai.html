AI CONNECTION

Connect your AI

Use your own AI app to look up and add records in your PathSix CRM. Add PathSix once, sign in, approve the access you want, and keep using it.

Add it to your AI app

Claude

  1. Open Settings.
  2. Open Connectors.
  3. Choose Add custom connector.
  4. Paste this URL:{{ mcp_url }}
  5. Select Add.
  6. Select Connect, then sign in to PathSix.

Free plans allow one custom connector. On Team and Enterprise plans, an owner adds it for the organization.

ChatGPT

  1. On the web, open Plugins.
  2. Choose +.
  3. Choose Add custom MCP server.
  4. Enter PathSix CRM as the name.
  5. Paste this URL:{{ mcp_url }}
  6. Choose OAuth for authentication.
  7. Review the warning and select I understand and want to continue.
  8. Select Create as a plugin, then sign in to PathSix.

Availability depends on your ChatGPT plan, and workspace admins may need to allow custom servers.

Gemini

  1. Go to gemini.google.com.
  2. Open Settings.
  3. Open Connected apps.
  4. Choose to add a custom app.
  5. Paste this URL:{{ mcp_url }}
  6. Sign in to PathSix when prompted.

Custom apps can currently be added only on the web. They then also appear in the mobile app.

Claude Code

  1. In your terminal, run:claude mcp add --transport http pathsix {{ mcp_url }}
  2. In Claude Code, run /mcp.
  3. Choose pathsix, then sign in to PathSix.

VS Code

  1. Open or create .vscode/mcp.json.
  2. Add this server:{"servers": {"pathsix": {"type": "http", "url": "{{ mcp_url }}"}}}
  3. Select Start above the server.
  4. Sign in to PathSix when prompted.

Menu names change from time to time. Any AI app that supports remote MCP servers with OAuth sign-in can connect the same way. You don’t need a client ID or secret.

What happens next

  • Your AI app opens a PathSix page. Sign in{% if staging %} with your staging test account{% endif %} and choose Allow access.
  • It can only see records your PathSix account can already see.
  • Each new lead needs your separate approval before it is saved.
  • Access stays on while you use it. It ends after {{ idle_days }} days without use, or {{ consent_days }} days after you approve it.

Review or revoke access anytime in your AI connections.
