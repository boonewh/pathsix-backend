AI CONNECTION

Connect your AI

Use your own AI app to look up and add records in your PathSix CRM. Add PathSix once, sign in, approve the access you want, and keep using it.

Your PathSix connection URL

{{ mcp_url }}

Paste this URL wherever your AI app asks for a custom connector, app or MCP server. You don’t need a client ID or secret.

Add it to your AI app

Claude

In Settings, open Connectors and choose Add custom connector. Paste the URL, select Add, then Connect. Free plans allow one custom connector. On Team and Enterprise plans, an owner adds it for the organization.

ChatGPT

On the web, open Plugins, choose +, then Add custom MCP server. Paste the URL, choose OAuth sign-in, review the warning and create it. Availability depends on your ChatGPT plan, and workspace admins may need to allow custom servers.

Gemini

At gemini.google.com, open Settings, then Connected apps, and add a custom app with the URL. Custom apps can currently be added only on the web; they then also appear in the mobile app.

Claude Code

Run claude mcp add --transport http pathsix {{ mcp_url }}, then use /mcp to sign in.

VS Code

Add a server with type http and the URL to .vscode/mcp.json, start it, then sign in when prompted.

Menu names change from time to time. Any AI app that supports remote MCP servers with OAuth sign-in can connect the same way.

What happens next

  • Your AI app opens a PathSix page. Sign in{% if staging %} with your staging test account{% endif %} and choose Allow access.
  • It can only see records your PathSix account can already see.
  • Each new lead needs your separate approval before it is saved.
  • Access stays on while you use it. It ends after {{ idle_days }} days without use, or {{ consent_days }} days after you approve it.

Review or revoke access anytime in your AI connections.
